# MAMD

A Maritime AI model dashboard

## Software Requirements
```
- Cuda 12.4.1
- CudNN 9.21.1
- Dot 14.1.5
```

## Usage

MAMD is currently limited to evaluating ONNX models.

### Testing

To test and evaluate ONNX models, start by booting MAMD with the following command:
```
python src\main.py
```

This will satisfy dependencies and render UI elements.

## Troubleshooting

You may experience runtime errors.

### Packages

Start with your dependencies. Package "xxxx" may need to be updated:
```
pip install --upgrade --force-reinstall xxxx
```

OR otherwise.
